# LifeWeave

LifeWeave is an open-source biodiversity project focused on centralizing species knowledge from multiple data sources.

The objective is to provide a unified and consistent view of biodiversity data by aggregating information from external providers such as taxonomic databases, biodiversity repositories, and scientific sources.

## Vision

Biodiversity knowledge is currently scattered across many platforms and datasets.

LifeWeave aims to bring this information together, making it easier to discover, explore, and understand species and the relationships between them.

## Goals

- Collect species data from multiple sources.
- Normalize and consolidate biodiversity information.
- Provide a unified API for accessing species knowledge.
- Build a foundation for future ecological relationship analysis.

## Current Scope

The project currently focuses on:

- Taxonomic data aggregation.
- Species information management.
- Data normalization and synchronization.
- Knowledge centralization.

## Project Status

LifeWeave is in active development and the domain model is evolving as new requirements and data sources are explored.
